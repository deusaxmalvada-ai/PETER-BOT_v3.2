PETER-BOT v2 — instalação (Termux)

1) Copia o zip para a pasta Downloads e corre:
   termux-setup-storage
   pkg install unzip -y
   cd ~ && unzip -o ~/storage/downloads/PETER-BOT-v2.zip -d ~/peter-v2
   sh ~/peter-v2/PETER-BOT-v2/instalar.sh

2) Edita os números do dono (só os teus):
   nano ~/PETER-BOT/src/config.js

3) Inicia (com reinício automático):
   cd ~/PETER-BOT && sh start.sh

O instalador faz backup de tudo (menos auth) e NÃO mexe em: auth, m2, core, panels, personality.
Para voltar atrás: copia ~/PETER-BOT/_old/index-*.js e bot-*.js de volta.

IA DE CONVERSA (opcional, grátis):
1) Cria uma chave grátis em https://aistudio.google.com/app/apikey
2) sh ~/PETER-BOT/ia-config.sh   (provedor: gemini · cola a chave)
3) Reinicia o bot e manda .ia no WhatsApp para ver o estado.
Sem chave, o bot usa o banco de frases local.
